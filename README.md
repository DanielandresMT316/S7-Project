Project-S7
Tenemos como objetivo el analisis de negocio usando 3 datasets (clientes, uso_real y planes) para que ConnectaTel entienda cómo se comportan sus usuarios según edad, volumen de llamadas/mensajes y nivel de consumo. El análisis nos llevara por diferentes pasos los cuales nos ayudaras a: a. Ver la informacion que poseemos en nuestros diferentes data set ayudandonos a asociarnos con los mismos. b. Identificar problemas de calidad buscando sentinels, fechas fuera de lugar y nulos, despues haremos una limpieza basica del mismo eliminando lo nulos o imputandolos, remplazando sentinels y cambiando fechas. c. analizaremos las metricas con los numeros que poseemos para identificar comportamientos tipicos y extremos. d. Crearemos diferentes boxplot e histogramas buscando outliers entre estos. e. Vamos a crear diferentes segmentaciones para ver los comportanmientos de los clientes basandonos en edad, tipo de plan, y servicio ofrecido para crear diferentes opciones a seguir. f. veremos un resumen ejecutivo de todo lo que vimos a lo largo de nuestro analisis para ver que encontramos en nuestro analisis.
